# Bounded ordinary-core support record

This is an implementation record, not an owner-signed platform policy, legal
clearance, calibration certificate or historical-version migration certificate.

| Surface | Scope |
|---|---|
| Ordinary donor-level local EBMF | Primary route. Requested/effective configuration, known fixed noise and actual refit settings have small deterministic tests. Documented fallback changes are warned and recorded; stability targets the full procedure including that ladder. |
| Current serialized fits with declared units and trained replay | Small linear/polynomial serialization and native projection fixtures. Query composition does not redefine the trained design. No automatic units discovery. |
| Unknown-unit reference projection | Refused before native inference. Refit with truthful units declared; projection-time `feature_scale` is query-only. Original reference objects are not relabeled. |
| Legacy residualized fits missing trained replay | Refit required. Preserved factors may remain extractable; automatic projection migration is not promised. Synthetic old-schema fixtures are not authentic historical binary certification. |
| Installed node-accounting oracle | `validation/analyze_corrected.R` is byte-identical to the retained historical corrected analyzer and runs from the installed package. An accounting fixture is not empirical error calibration. |
| Torch, basilisk, SuperCell, mcRigor, mashr and sva integration | Optional and not established by ordinary-core checks. Existing support/refusal guards remain; do not infer backend numerical equivalence or cross-platform success. |
| Platform coverage | Executed evidence is Linux / R 4.4.2 only. Configured CI is not executed coverage. Broader/minimum-R support and allowed optional-dependency notes need owner acceptance. |

Warning fixtures assert complete expected warning sets, including routing and
fallback notices. A new, changed or missing warning fails those assertions.
Actual numerical fallbacks are still emitted by the package; tests do not disable
them, force an estimator or certify scientific stability.
