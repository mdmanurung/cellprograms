# cellprograms: Cell-Type-Specific Transcriptional Programs via EBMF

<div class="d-none name">

`cellprograms-package.Rd`

</div>

</div>

<div class="ref-description section level2">

Discover cell-type-specific transcriptional programs from pseudobulk single-cell RNA-seq data using empirical-Bayes matrix factorization ('flashier'), with canonicalization, stability assessment, cross-cell-type coordination detection, shared-vs-specific program assessment ('mashr'), and artifact-gene masking. Programs are discovered locally within each cell type; cross-cell-type coordination is investigated subsequently, never assumed.
