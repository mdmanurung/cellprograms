## Scientific contract to freeze before main evaluation
Donors are the inferential units. Local EBMF factors are nodes. A coordinated program contains at most one node per cell type; activity alignment, including opposite signs, is the target. Gene reuse is a secondary comparator and cannot qualify an activity detector on its own. No causal or unmeasured-confounder claim.

The selected activity detector is package `node_rank`, with complete and sign-consistent linkage. `pa_cc`, `subspace_sum` and `gene_match` are descriptive comparators; no held-out method selection. `pa_cc` has a separate cell-type membership tier and cannot provide identifiable program nodes. Node methods are scored at both node and cell-type tiers. Export all tested edges and called flags alongside memberships: edge probabilities do not become cluster probabilities.

The selected package implementation must clear every registered qualification gate. Use a joint donor permutation across all pairs in each iteration, independently permuting each cell type within its named strata and preserving all factor columns together. Confirm exchangeability assumptions and empirical calibration under structured missingness. Test zero-factor, one-cell-type, constant-score, empty-edge, identifier and strata failures. Never let a failed test become an empty biological call.

## Simulator and fit
Use 10 cell types, 100 donors, the existing 100/75/50 observation tiers with 30-donor small-cell core, 2,000 genes, 40-gene programs, 1–2 private programs per cell type, R100/R50/R20. Allow per-program amplitudes and an explicit small/large R20 membership factor. Correct `act_cor` so it denotes pairwise correlation (shared latent coefficient sqrt(act_cor)). Preserve same/half/disjoint gene variants and independent-activity/same-gene negative control.

The measured nuisance includes Institute plus a donor variable with within-Institute variation; both are recorded and explicitly adjusted. Add an unadjusted positive nuisance-control arm. Assess exchangeability with residualized scores rather than claiming an exact test after continuous regression. Keep heteroscedasticity as a prespecified stress condition; record whether the calibration gate limits use there. Pin fits: point_laplace, Kmax 10, var_type 1, all genes, center TRUE, backfit/nullcheck TRUE, residualize measured covariates, seed schedule independent of method. Record fallbacks, ranks, runtime and versions.

## Truth and scoring
Match fitted nodes per cell type to known activity using absolute score correlation on observed donors after the same measured adjustment. Use a one-to-one maximum-weight assignment with a prespecified correlation threshold; include nuisance and private nodes to disambiguate spurious calls. Matching exists only inside evaluation; production never sees truth. Match clusters to R100/R50/R20 one-to-one by member-node overlap, with deterministic ties. Unmatched or duplicate clusters count as spurious. Found requires recall >= .5, precision >= .5 and >=2 correctly matched members. Report node recall, precision, cell-type metrics, breadth error, Found, decoy and spurious dataset incidence, unmatchable nodes and callability. Do not equate absent/failed results with tested negatives.

The oracle uses truth scores and the same missing donors, adjustment, alpha and clustering. It includes private and nuisance scores. No activity oracle signal is present in genes_only mode; any calls there are false for the primary target. A loading-truth oracle is secondary only. Report empirical floors and algorithm losses separately from EBMF losses.

## Pilot, frozen main run and eligibility
Pilot seeds are disjoint, discarded for validation. Pilot chooses amplitudes, weak/strong levels and permutation/runtime budget; it must examine all breadths and small-cell detectability. One-to-one matching, selection rules and calibration gates are frozen before evaluation. Main replicate counts must support paired confidence intervals and precise null calibration; plan 200 paired replicates per primary cell and 100 per secondary stress cell, adjusted prospectively after runtime/power pilot and independent review. Use at least 999 permutations, 4,000 paired bootstrap resamples, binomial exact intervals, separately seeded RNG streams, and immutable versioned output roots.

Primary cells: null, genes_only, act+genes, act_only; R20-small/large variants are explicit. Secondary: act+half, activity correlation .7, weaker/stronger signal and heteroscedastic stress. A primary negative control qualifies only if its dataset-level spurious/decoy rate estimate <= .05 and the exact 95% upper bound <= .10. Predefine how multiple negative-control cells are gated and do not use failed controls to qualify a candidate. Positive nuisance controls must demonstrate nuisance detectability before adjustment.

Require Found-rate improvement on R50 and R20 over the fair cell-type pa_cc tier with paired 95% lower bound >0 and a meaningful pilot-fixed margin; require R100 non-loss and decoy/spurious non-inferiority. Condition detectability claims on oracle performance, without discarding hard datasets. If pa_cc cannot give a fair program-level baseline, keep tiers separate and select on absolute node-level criteria plus membership comparisons. Formal margins and replicates are finalized by reviewed preregistration, not chosen from main results.
